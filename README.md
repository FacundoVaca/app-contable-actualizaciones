# App Contable: actualizaciones

Acá está el instalador de la última versión de App Contable.

**Para instalarla:** bajá [app-contable-setup.exe](https://github.com/FacundoVaca/app-contable-actualizaciones/raw/main/app-contable-setup.exe) y abrilo. Si Windows muestra "Windows protegió su PC", tocá "Más información" y después "Ejecutar de todas formas".

Después la app se actualiza sola cada vez que se abre.
